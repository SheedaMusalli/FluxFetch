## FluxFetch v1.0.0

FluxFetch v1.0.0 is the first release in the FluxFetch line: a Windows download manager built to make multi-connection transfers easier to control, monitor, and recover.

### Highlights

- Parallel HTTP/HTTPS transfers with selectable network adapters, resumable segments, retry handling, and per-adapter progress.
- Chrome and Edge handoff for supported links, plus clipboard monitoring and a searchable download library.
- Queue batching and scheduling, download speed limits, proxy routing, and per-site authentication settings.
- Internet and combined-network speed tests with selectable duration.
- ZIP/RAR archive preview and selective extraction, and optional torrent handoff to a local qBittorrent Web UI.
- **OmniLink for Steam** is a key FluxFetch feature: it attempts to route eligible Steam download connections across selected adapters so independent Internet connections can contribute bandwidth at the same time. For example, use Ethernet through Router A, Wi-Fi through Router B, and an Android phone connected by USB while it uses Router C's Wi-Fi, if the phone supports sharing that Wi-Fi uplink over USB. This can make more aggregate Internet capacity available to eligible Steam transfers. Adapters on the same router or Internet line share that connection and do not add bandwidth.
- **OmniLink can improve Steam download throughput, but cannot guarantee faster downloads in every setup.** Steam's CDN, connection behavior, network routes, driver compatibility, and available capacity affect results. OmniLink requires Windows administrator approval and compatible drivers.

### Downloads

- `fluxfetch-1.0.0-setup.exe` — Windows x64 installer.
- `FluxFetch-Chrome.zip` — unpacked extension for Chrome/Edge Developer mode.
- `FluxFetch-Chrome.crx` — extension package where supported.
- `SHA256SUMS.txt` — checksums for release files.

### Requirements and notes

- Windows 10/11 x64. The browser extension must be loaded unpacked; it is not distributed through the Chrome Web Store.
- Torrent support uses your own qBittorrent installation and its local Web UI; FluxFetch does not include a torrent engine.
- Combined download throughput depends on the server, network interfaces, routing, and connection. It cannot guarantee higher speeds for every download.
- The speed test sends timed requests to Cloudflare's public measurement endpoints.
- A phone may not support sharing a Wi-Fi uplink over USB tethering. Test your own network setup and observe Steam's throughput; results depend on the factors above.
