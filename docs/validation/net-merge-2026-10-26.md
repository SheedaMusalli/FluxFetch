## Remaining external validation and prerequisites

The experimental WFP source, INF, WDK project, Go controller and signing scripts
are included in this repository. The driver build was attempted and reported
missing Visual Studio C++ Build Tools and Windows SDK/WDK. It has not been compiled,
loaded, Driver-Verifier-tested or certified. The ordinary FluxFetch Start button
uses the verified upstream Wintun driver.

No code-signing certificate was present in the current-user code-signing
certificate store. The Net Merge and FluxFetch executables and installer remain
unsigned; electron-builder's generic “signing” progress messages do not establish
that a signature exists. Wintun retains its valid original publisher signature.
Publisher signing requires a certificate; normal production deployment of the
new kernel driver additionally requires Microsoft hardware signing.

Actual adapter discovery found one Ethernet connection. Multi-WAN throughput,
network failover on real hardware, and system-wide TUN route changes were not
tested on this machine. No bandwidth or CPU improvement measurement is claimed.
