# FluxFetch for Firefox

Install FluxFetch for Firefox from [Mozilla Add-ons](https://addons.mozilla.org/en-US/firefox/addon/fluxfetch-integration-module/). The add-on needs the FluxFetch Windows app to handle downloads.

For local development, open `about:debugging` → **This Firefox** → **Load Temporary Add-on…** and choose this folder's `manifest.json`. Temporary add-ons must be loaded again after Firefox restarts. See the [browser setup guide](https://github.com/SheedaMusalli/FluxFetch-Download-Manager/blob/main/docs/BROWSER-SETUP.md).
